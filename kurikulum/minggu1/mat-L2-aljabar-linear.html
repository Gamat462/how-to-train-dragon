Norma dan sudut — kenapa ini nanti jadi “kemiripan”

import numpy as np
a = np.array([3.0, 4.0])
b = np.array([6.0, 8.0])       # arah sama, dua kali panjang
c = np.array([-4.0, 3.0])      # tegak lurus a

for nama, v in (("a", a), ("b", b), ("c", c)):
    print(nama, "panjang =", np.linalg.norm(v))

def cos_sudut(u, v):
    return (u @ v) / (np.linalg.norm(u) * np.linalg.norm(v))

print("cos(a,b) =", cos_sudut(a, b))
print("cos(a,c) =", cos_sudut(a, c))
HARUS MUNCUL 
a panjang = 5.0
b panjang = 10.0
c panjang = 5.0
cos(a,b) = 1.0
cos(a,c) = 0.0
PERHATIKAN cos = 1 berarti arahnya persis sama. cos = 0 berarti tegak lurus — tidak berbagi informasi apa pun. Angka inilah yang dipakai sistem rekomendasi untuk bilang “pelanggan ini mirip pelanggan itu”, dan yang dipakai pencarian teks untuk bilang “dokumen ini mirip kuerimu”.

Matriks sebagai transformasi, bukan tabel

import numpy as np
v = np.array([1.0, 1.0])
R = np.array([[0.0, -1.0],
              [1.0,  0.0]])          # putar 90 derajat
S = np.array([[3.0, 0.0],
              [0.0, 0.5]])           # regangkan x, gepengkan y

print("v      =", v)
print("R @ v  =", R @ v)
print("S @ v  =", S @ v)

np.linalg.solve, dan selalu periksa hasilnya

import numpy as np
A = np.array([[2., 1., 1.],
              [1., 3., 2.],
              [1., 0., 4.]])
b = np.array([12., 17., 14.])

x = np.linalg.solve(A, b)
print("x        =", x)
print("A @ x    =", A @ x, " (harus = b)")
print("selisih  =", np.abs(A @ x - b).max())
print("det(A)   =", np.linalg.det(A))
HARUS MUNCUL

Kebiasaan yang harus kamu bawa dari kertas kerja: selalu hitung A @ x dan bandingkan dengan b. Itu tie-out, persis konsep yang sama. Jangan pernah memakai keluaran solver tanpa mencocokkannya kembali.

Ketika determinan nol — dan kenapa ini penting untuk regresi

import numpy as np
# kolom ketiga = kolom pertama + kolom kedua  (informasi berulang)
B = np.array([[1., 2., 3.],
              [4., 5., 9.],
              [7., 8., 15.]])
print("det(B)  =", np.linalg.det(B))
print("rank(B) =", np.linalg.matrix_rank(B), "dari 3 kolom")
try:
    np.linalg.solve(B, np.array([1., 2., 3.]))
except np.linalg.LinAlgError as e:
    print("solve GAGAL:", e)
HARUS MUNCUL 
det(B)  = 0.0
rank(B) = 2 dari 3 kolom
solve GAGAL: Singular matrix
Ini bukan kejadian langka — ini terjadi di data kerja setiap saat. Kamu memasukkan “omzet”, “PPN”, dan “omzet termasuk PPN” sebagai tiga kolom prediktor. Kolom ketiga adalah jumlah dua yang pertama. Matriksnya singular, koefisien regresimu jadi tidak stabil, dan tandanya bisa terbalik tanpa peringatan apa pun. Namanya multikolinearitas, dan np.linalg.matrix_rank mendeteksinya dalam satu baris.

Masalahnya: 200 persamaan, 3 hal yang dicari

Di Hari 3, jumlah persamaan sama dengan jumlah yang dicari, jadi ada jawaban persis. Di data nyata kamu punya 200 baris dan cuma 3 koefisien. Tidak ada jawaban persis — yang ada jawaban paling tidak meleset.

import numpy as np
np.random.seed(7)
n  = 200
x1 = np.random.uniform(0, 40, n)      # jumlah pengunjung
x2 = np.random.uniform(0, 10, n)      # intensitas promo
y  = 150_000 + 8_500*x1 + 22_000*x2 + np.random.normal(0, 30_000, n)

X = np.column_stack([np.ones(n), x1, x2])     # kolom 1 = intersep
print("bentuk X:", X.shape, " bentuk y:", y.shape)
Kolom pertama berisi angka 1 semua. Itulah cara intersep masuk ke dalam matriks — sehingga β₀ diperlakukan sama seperti koefisien lain, bukan kasus khusus.
2

Persamaan normal, diketik apa adanya

Rumus yang muncul di setiap buku teks regresi adalah β = (XᵀX)⁻¹Xᵀy. Sekarang kamu bisa mengetiknya persis seperti itu.

beta_normal = np.linalg.inv(X.T @ X) @ X.T @ y
beta_lstsq  = np.linalg.lstsq(X, y, rcond=None)[0]

print("persamaan normal :", beta_normal)
print("np.linalg.lstsq  :", beta_lstsq)
print("selisih maksimum :", np.abs(beta_normal - beta_lstsq).max())
print("nilai sebenarnya : [150000. 8500. 22000.]")

resid = y - X @ beta_lstsq
print("R^2 =", 1 - resid.var()/y.var())

Kenapa lstsq lebih baik daripada inv — dan kapan itu penting

Satu. Koefisiennya raksasa dan berlawanan tanda: −77.568 dan +77.571. Nilai sebenarnya yang saya tanam cuma 3. Model ini bilang satu kolom menaikkan omzet 77 ribu per satuan dan kolom kembarannya menurunkannya 77 ribu — omong kosong yang menghasilkan prediksi bagus.

Prediksinya sendiri tetap benar — model ini meramal y dengan baik. Yang rusak hanya penjelasannya. Ini pembedaan yang wajib kamu bawa ke klien: model boleh dipakai untuk meramal dan sekaligus tidak boleh dipakai untuk menjawab “faktor mana yang paling berpengaruh”.

Matriks kovarian: inti Multivariate Statistics

± 2,5 jam
Tujuan hari ini: membaca matriks kovarian dan korelasi dengan benar, dan tahu kenapa penskalaan mengubah segalanya — syarat mutlak sebelum menyentuh PCA besok.
1

Hitung, lalu periksa dua sifat yang harus selalu benar

import numpy as np
np.random.seed(7)
n  = 200
x1 = np.random.uniform(0, 40, n)
x2 = np.random.uniform(0, 10, n)
y  = 150_000 + 8_500*x1 + 22_000*x2 + np.random.normal(0, 30_000, n)
D  = np.column_stack([x1, x2, y])

C = np.cov(D, rowvar=False)
R = np.corrcoef(D, rowvar=False)
np.set_printoptions(precision=4, suppress=True)
print("kovarian:\n", C)
print("korelasi:\n", R)
print("simetris?", np.allclose(C, C.T))
print("diagonal = varians?", np.allclose(np.diag(C), D.var(axis=0, ddof=1)))
HARUS MUNCUL 
korelasi:
 [[ 1.     -0.0089  0.8061]
 [-0.0089  1.      0.5274]
 [ 0.8061  0.5274  1.    ]]
simetris? True
diagonal = varians? True
CARA MEMBACANYA

Baca korelasinya: pengunjung↔omzet 0,8061, promo↔omzet 0,5274, pengunjung↔promo −0,0089 (praktis nol — memang saya buat saling bebas).

Dua sifat itu bukan hiasan: matriks kovarian selalu simetris dan diagonalnya selalu varians tiap kolom. Kalau punyamu tidak, kamu salah sumbu (rowvar).

2

Kenapa kovarian mentah tidak bisa dibandingkan

Lihat kovarian mentahnya: pasangan pengunjung–omzet bernilai sekitar 1.094.700, pasangan pengunjung–promo bernilai −0,30. Bedanya jutaan kali. Apakah artinya yang pertama jauh lebih penting?

print("kovarian(x1, y) =", C[0, 2])
print("kovarian(x1, x2)=", C[0, 1])
print("korelasi(x1, y) =", R[0, 2])
print("korelasi(x1, x2)=", R[0, 1])
# ubah satuan y dari rupiah ke juta rupiah
D2 = D.copy(); D2[:, 2] /= 1e6
print("kovarian setelah ganti satuan:", np.cov(D2, rowvar=False)[0, 2])
print("korelasi setelah ganti satuan:", np.corrcoef(D2, rowvar=False)[0, 2])
INI JAWABANNYA Ganti satuan omzet dari rupiah ke juta rupiah, dan kovariannya turun sejuta kali — tapi korelasinya tidak bergerak sama sekali. Kovarian bergantung satuan; korelasi tidak. Itulah kenapa kamu membandingkan korelasi, bukan kovarian.
Dan ini yang akan menggigitmu besok di PCA. PCA bekerja pada kovarian. Kalau satu kolom bersatuan rupiah (jutaan) dan lainnya bersatuan “jumlah kunjungan” (puluhan), PCA akan melaporkan bahwa komponen pertama hampir seluruhnya adalah kolom rupiah — bukan karena ia lebih penting, tapi karena satuannya lebih besar. Selalu bakukan dulu.

Eigenvector: arah yang tidak berubah arah

Ingat Hari 2: matriks itu mesin yang mengubah vektor. Eigenvector adalah arah yang hanya diregangkan, tidak diputar, dan eigenvalue adalah faktor regangnya.

import numpy as np
A = np.array([[3., 1.],
              [1., 3.]])
w, V = np.linalg.eigh(A)
print("eigenvalue :", w)
print("eigenvector:\n", V)
for i in range(2):
    v = V[:, i]
    print(f"A @ v{i} =", A @ v, "   {:.1f} * v{} =".format(w[i], i), w[i]*v)
HARUS MUNCUL 
eigenvalue : [2. 4.]
A @ v0 = [-1.4142  1.4142]    2.0 * v0 = [-1.4142  1.4142]
A @ v1 = [2.8284 2.8284]      4.0 * v1 = [2.8284 2.8284]

Untuk kedua eigenvector, A @ v memberi hasil yang identik dengan λ · v. Itulah definisinya: Av = λv.

2

PCA dari nol: enam baris

import numpy as np
np.random.seed(7)
n  = 200
x1 = np.random.uniform(0, 40, n); x2 = np.random.uniform(0, 10, n)
y  = 150_000 + 8_500*x1 + 22_000*x2 + np.random.normal(0, 30_000, n)
D  = np.column_stack([x1, x2, y])

Z  = (D - D.mean(0)) / D.std(0, ddof=1)      # BAKUKAN dulu (pelajaran Hari 5)
Cz = np.cov(Z, rowvar=False)
w, V = np.linalg.eigh(Cz)
urut = np.argsort(w)[::-1]; w, V = w[urut], V[:, urut]

print("eigenvalue     :", w)
print("proporsi ragam :", w / w.sum())
print("kumulatif      :", np.cumsum(w / w.sum()))
print("jumlah eigenvalue:", w.sum(), "(harus = jumlah kolom = 3)")
HARUS MUNCUL
Komponen Eigenvalue Proporsi ragam Kumulatif
PC11,959265,31%65,31%
PC21,008233,61%98,91%
PC30,03271,09%100,00%

Jumlah eigenvalue = 3,000000, sama dengan jumlah kolom. Itu selalu benar setelah pembakuan, dan itu pemeriksaan mandiri gratis.

CARA MEMBACANYA Dua komponen menjelaskan 98,91% keragaman tiga kolom. Artinya kolom ketiga hampir tidak membawa informasi baru — masuk akal, karena omzet memang dibangun dari dua kolom lainnya.

Adu dengan sklearn — harus sama

from sklearn.decomposition import PCA

print("sklearn :", pca.explained_variance_ratio_)
print("tanganmu:", w / w.sum())
print("selisih maksimum:", np.abs(pca.explained_variance_ratio_ - w/w.sum()).max())

skor_tangan  = Z @ V[:, 0]
skor_sklearn = pca.transform(Z)[:, 0]
print("skor PC1 sama (tanda boleh beda)?",
      np.allclose(np.abs(skor_tangan), np.abs(skor_sklearn)))
print("muatan PC1:", V[:, 0])

sklearn : [0.6531 0.3361 0.0109]
tanganmu: [0.6531 0.3361 0.0109]
selisih maksimum: 4.44e-16

PERHATIKAN Selisih 4,44 × 10⁻¹⁶ adalah batas presisi komputer. Hitunganmu dan sklearn identik. Kamu sekarang tahu persis apa yang dilakukan PCA, bukan sekadar bisa memanggilnya.
Soal tanda: eigenvector boleh dibalik tanpa mengubah arti — kalau v eigenvector, −v juga. Itu sebabnya kita membandingkan nilai mutlaknya. Jangan kaget kalau grafik PCA-mu terlihat tercermin dibanding punya orang lain; itu bukan kesalahan.
Jebakan menafsirkan muatan. Muatan PC1 = [0,5919, 0,3841, 0,7086] artinya PC1 adalah campuran ketiga kolom, bukan “kolom omzet”. PCA menghasilkan sumbu baru yang tidak punya nama. Kalau klienmu bertanya “PC1 itu apa?”, jawaban jujurnya adalah menyebutkan muatannya — bukan mengarang label.

Kunci jawaban

2. Supaya intersep β₀ ikut terhitung dalam satu operasi matriks yang sama, bukan sebagai kasus khusus.

3. Matriksnya singular — ada kolom yang merupakan kombinasi kolom lain. Koefisien jadi tidak tunggal dan tidak stabil; tandanya bisa terbalik. Periksa dengan matrix_rank dan cond.

4. β = (XᵀX)⁻¹Xᵀy — dan dalam praktik pakai np.linalg.lstsq, bukan inv.

5. 5. Jumlah eigenvalue matriks korelasi selalu sama dengan jumlah kolomnya, karena diagonalnya semua 1.

6. Komponen pertama akan didominasi kolom bersatuan besar, semata karena satuannya — bukan karena informasinya. Hasilnya menyesatkan.

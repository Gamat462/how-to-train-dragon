HARI 3

Backpropagation, dihitung tangan lalu dibuktikan

± 3,5 jam
Tujuan hari ini: menurunkan sendiri gradien jaringan dua lapis dengan aturan rantai, lalu membuktikannya benar dengan pemeriksaan gradien numerik — teknik yang dipakai setiap peneliti untuk memvalidasi kode barunya.
1

Aturan rantai, dalam satu kalimat

Backpropagation bukan algoritma baru. Ia aturan rantai kalkulus yang diterapkan berulang, dari belakang ke depan.

Jalur maju:
    Z1 = X @ W1 + b1        A1 = tanh(Z1)
    Z2 = A1 @ W2 + b2       A2 = sigmoid(Z2)
    L  = cross_entropy(A2, y)

Untuk tahu seberapa besar W1 mempengaruhi L, rantai mundur:

    dL/dW1 = dL/dA2 · dA2/dZ2 · dZ2/dA1 · dA1/dZ1 · dZ1/dW1

Itu saja. "Backprop" = menghitung rantai itu efisien,
menyimpan hasil antara, bukan menghitung ulang.
Kenapa disebut “mundur”: suku pertama rantainya adalah di ujung keluaran, dan tiap suku berikutnya melangkah satu lapis ke belakang. Kamu menghitung kesalahan di ujung, lalu menyalahkan mundur lapis demi lapis.
2

Tulis kodenya

import numpy as np
sig = lambda z: 1/(1+np.exp(-z))
X = np.array([[0,0],[0,1],[1,0],[1,1]], float)
y = np.array([0, 1, 1, 0], float)
n = len(X)

rng = np.random.default_rng(42)
W1 = rng.normal(0,1,(2,2)); b1 = np.zeros(2)
W2 = rng.normal(0,1,(2,1)); b2 = np.zeros(1)

def maju(X, W1, b1, W2, b2):
    Z1 = X @ W1 + b1; A1 = np.tanh(Z1)
    Z2 = A1 @ W2 + b2; A2 = sig(Z2)
    return Z1, A1, Z2, A2

def rugi(A2, y):
    e = 1e-12
    return -np.mean(y*np.log(A2.ravel()+e) + (1-y)*np.log(1-A2.ravel()+e))

Z1, A1, Z2, A2 = maju(X, W1, b1, W2, b2)
print("rugi awal =", rugi(A2, y))

# ---- backprop, empat baris inti ----
dZ2 = (A2 - y.reshape(-1,1)) / n
dW2 = A1.T @ dZ2;            db2 = dZ2.sum(0)
dZ1 = (dZ2 @ W2.T) * (1 - A1**2)      # turunan tanh = 1 - tanh^2
dW1 = X.T @ dZ1;             db1 = dZ1.sum(0)
HARUS MUNCUL 
rugi awal = 0.928743
YANG PALING SERING BIKIN BINGUNG Perhatikan baris dZ2 = (A2 − y)/n. Turunan cross-entropy terhadap keluaran sigmoid menyederhana menjadi “prediksi dikurangi kebenaran”. Kesederhanaan itu bukan kebetulan — pasangan sigmoid + cross-entropy dipilih justru karena menghasilkan bentuk ini.

Buktikan kodemu benar — pemeriksaan gradien

Bagaimana kamu tahu turunan yang kamu tulis tidak salah? Bandingkan dengan turunan numerik dari MAT L3 Hari 1.

def numerik(param, idx):
    eps = 1e-6
    asli = param[idx]
    param[idx] = asli + eps; a = rugi(maju(X,W1,b1,W2,b2)[3], y)
    param[idx] = asli - eps; b = rugi(maju(X,W1,b1,W2,b2)[3], y)
    param[idx] = asli
    return (a - b) / (2*eps)

for nama, par, grad in (("W1", W1, dW1), ("W2", W2, dW2)):
    for idx in np.ndindex(par.shape):
        g = numerik(par, idx)
        print(f"d{nama}{idx}  backprop={grad[idx]:>11.8f}"
              f"  numerik={g:>11.8f}  selisih={abs(grad[idx]-g):.2e}")

Lingkar pelatihan lengkap

import numpy as np
sig = lambda z: 1/(1+np.exp(-z))
X = np.array([[0,0],[0,1],[1,0],[1,1]], float)
y = np.array([0,1,1,0], float); n = len(X)
rng = np.random.default_rng(42)

W1 = rng.normal(0,1,(2,4)); b1 = np.zeros(4)      # 4 neuron tersembunyi
W2 = rng.normal(0,1,(4,1)); b2 = np.zeros(1)
lrate = 0.5; jejak = []

for it in range(5001):
    Z1 = X @ W1 + b1; A1 = np.tanh(Z1)
    Z2 = A1 @ W2 + b2; A2 = sig(Z2)
    jejak.append(-np.mean(y*np.log(A2.ravel()+1e-12) +
                          (1-y)*np.log(1-A2.ravel()+1e-12)))
    dZ2 = (A2 - y.reshape(-1,1)) / n
    dW2 = A1.T @ dZ2; db2 = dZ2.sum(0)
    dZ1 = (dZ2 @ W2.T) * (1 - A1**2)
    dW1 = X.T @ dZ1;  db1 = dZ1.sum(0)
    W2 -= lrate*dW2; b2 -= lrate*db2
    W1 -= lrate*dW1; b1 -= lrate*db1

for it in (0, 10, 100, 500, 1000, 2000, 5000):
    print(f"iterasi {it:>5}  rugi = {jejak[it]:.6f}")

import numpy as np
from sklearn.metrics import confusion_matrix, classification_report
from sklearn.neural_network import MLPClassifier
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

# data timpang: hanya 3% kelas positif -- seperti deteksi kecurangan
X, y = make_classification(n_samples=4000, n_features=10, weights=[0.97],
                           flip_y=0.01, random_state=5)

print(confusion_matrix(yte, m.predict(Xte)))
print(classification_report(yte, m.predict(Xte), digits=4))

LAKUKAN Hitung sendiri precision-nya dari matriks itu: 15 / (15+11) = 57,7%. Bandingkan dengan hasil Bayes di MAT L1 Hari 4 (32,1%). Pola yang sama muncul lagi, dan sekarang kamu punya dua cara menghitungnya.
Pada data yang timpang, model yang tidak melakukan apa-apa sudah mendapat akurasi tinggi. Melaporkan akurasi saja pada kasus seperti ini adalah bentuk penyesatan yang paling mudah dilakukan tanpa niat buruk. Yang harus dilaporkan: recall (berapa banyak kasus nyata yang tertangkap) dan precision (berapa banyak alarm yang benar) — dan ingat Bayes di MAT L1 Hari 4: pada kejadian langka, precision akan rendah bahkan untuk model yang bagus.

import numpy as np
from sklearn.neural_network import MLPClassifier
skor = []
for s in range(10):
    mm = MLPClassifier(hidden_layer_sizes=(64,), max_iter=3000,
                       random_state=s).fit(Xtr, ytr)
    skor.append(mm.score(Xte, yte))
skor = np.array(skor)
print("10 seed:", skor.round(4))
print(f"median {np.median(skor):.4f}  min {skor.min():.4f}"
      f"  max {skor.max():.4f}  rentang {skor.max()-skor.min():.4f}")
LAKUKAN Jalankan, lalu tulis satu kalimat laporan dengan format ini: “Akurasi uji median 0,xxxx dari 10 seed (rentang 0,xxxx–0,xxxx).” Itu kalimat yang bisa ditelaah orang. “Akurasi 0,xxxx” tidak.
Kalau kamu menjalankan 10 seed lalu melaporkan yang terbaik, itu bukan pelaporan — itu memilih hasil. Sama seperti mengintip hasil A/B test berulang kali sampai p-value-nya bagus, yang sudah kamu ukur akibatnya di Modul M7: tingkat false positive melonjak dari 5% ke 26%.

LAKUKAN Tulis kedelapan jawabanmu dulu.
Kunci jawaban

1. W1 = 5×8 = 40, b1 = 8, W2 = 8×1 = 8, b2 = 1. Total 57.

2. Turunan sigmoid maksimum 0,25, dan di z=4 sudah 0,0177. Pada jaringan berlapis, gradien lapis awal adalah hasil kali turunan tiap lapis: 0,25¹⁰ ≈ 9,5 × 10⁻⁷. Lapis awal berhenti belajar.

3. Kelas “1” menempati dua sudut yang berseberangan diagonal. Tidak ada satu garis lurus yang memisahkan pasangan diagonal dari pasangan diagonal lain. Terbukti: regresi logistik mendapat akurasi 0,5 dengan koefisien nol.

4. Membuktikan turunan analitik yang kamu tulis benar. eps=1e-12 buruk karena mengurangkan dua bilangan yang nyaris sama menghilangkan presisi float — hasilnya justru lebih meleset, bukan lebih tepat.

5. Overfitting: selisih 16 poin persen. Tindakan: perbesar regularisasi (alpha), kecilkan arsitektur, tambah data, atau early stopping. Perhatikan dari Hari 5: memperbesar alpha terlalu jauh menghapus keunggulan modelnya sekalian.

6. Belum tentu. Menjawab “negatif” untuk semuanya sudah memberi 0,97. Laporkan recall, precision, dan confusion matrix.

7. Bahwa fungsi ruginya tidak konveks, sehingga hasilnya memang bergantung inisialisasi. Laporkan median dan rentang dari ≥5 seed — bukan salah satu dari keduanya.

8. Ketika datanya tabular dan berukuran sedang, ketika modelnya harus bisa dijelaskan, ketika selisih akurasinya kecil, dan ketika kamu butuh hasil yang bisa diulang persis. Dari Hari 5: 3 parameter memberi 0,8548 lawan 132.609 parameter memberi 0,8952.

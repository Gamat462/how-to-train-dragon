2

QUERY() — SQL di dalam spreadsheet

Fungsi ini tidak ada di Excel, dan ini alasan terkuat memakai Sheets. Isinya benar-benar SQL.

=QUERY(A:D; "select B, sum(D) where C = 'Ojol' group by B order by sum(D) desc"; 1)

Bacanya:
  A:D   -> rentang datanya
  B, D  -> HURUF KOLOM, bukan nama. B = cabang, D = nilai
  1     -> jumlah baris judul yang harus dilewati

Diuji atas 500 baris penjualan Juni 2026. SQL, pandas, dan QUERY memberi angka yang sama persis.

Jebakan terbesar QUERY: ia memakai HURUF KOLOM, bukan nama kolom. Kalau seseorang menyisipkan satu kolom di tengah, seluruh rumusmu diam-diam menghitung kolom yang salah — tanpa error. Ini kerabat dekat jebakan VLOOKUP yang sudah kamu pelajari.
LAKUKAN Sebelum menyerahkan sheet berisi QUERY, kunci kolomnya: Data → Protect sheets and ranges. Atau taruh sel pemeriksa: total hasil QUERY harus sama dengan =SUM() kolom sumbernya.

ARRAYFORMULA memecahkan masalah nyata: rumus yang diseret ke bawah berhenti di baris terakhir yang ada saat itu. Ketika data bertambah, baris baru tidak punya rumus — dan totalmu diam-diam kurang. Ini penyebab yang sama dengan “rentang pivot tidak ikut baris baru” di modul Excel.
IMPORTRANGE menarik data klien ke berkas lain. Sebelum memakainya untuk data klien, baca ulang Bekal Rahasia Klien: siapa saja yang punya akses ke sheet tujuan otomatis bisa melihat data sumbernya.

HARI 3

Membaca DAG Airflow tanpa memasang Airflow

± 3 jam
Tujuan hari ini: bisa menjawab pertanyaan “kenapa laporan pagi ini kosong?” dengan membaca berkas DAG — persis yang diminta lowongan Moladin.
1

Apa yang sebenarnya diminta

Kutipan apa adanya dari lowongan Moladin: “Basic comfort reading or modifying Airflow DAGs to check data dependencies and pipeline execution health.”

Perhatikan kata reading. Mereka tidak meminta kamu membangun platform data. Mereka meminta kamu bisa membuka satu berkas dan menjawab: kenapa laporannya belum ada.

KABAR BAIKNYA DAG adalah berkas Python biasa. Kamu sudah bisa membaca Python sejak Bekal Python. Yang perlu ditambahkan cuma lima istilah dan satu operator.

2

Berkas DAG sungguhan

with DAG(
    dag_id="laporan_harian_penjualan",
    default_args={"owner":"tim-data", "retries":2,
                  "retry_delay":timedelta(minutes=5), "email_on_failure":True},
    start_date=datetime(2026, 1, 1),
    schedule="0 6 * * *",
    catchup=False,
) as dag:

    tarik_pos       = PythonOperator(task_id="tarik_data_pos", ...)
    tarik_ecommerce = PythonOperator(task_id="tarik_data_ecommerce", ...)
    gabung          = PythonOperator(task_id="gabungkan_sumber", ...)
    uji_mutu        = PythonOperator(task_id="uji_mutu_data", ...)
    muat_gudang     = PostgresOperator(task_id="muat_ke_gudang", sql="sql/muat_harian.sql")
    kirim_email     = PythonOperator(task_id="kirim_ringkasan", ...)

    [tarik_pos, tarik_ecommerce] >> gabung >> uji_mutu >> muat_gudang >> kirim_email
LAKUKAN Baca baris terakhir dulu, selalu. Baris itu seluruh alurnya. Tanda kurung siku berarti dua tugas jalan bersamaan; tanda >> berarti yang kiri harus selesai dulu.
3

Bedah dengan Python — tanpa memasang Airflow

Karena DAG itu berkas Python, kamu bisa membedahnya dengan pustaka ast bawaan Python. Ini berguna nyata: kamu bisa memeriksa DAG di laptopmu tanpa akses ke server Airflow perusahaan.

import ast
pohon = ast.parse(open("laporan_harian_dag.py").read())

# semua task_id
for n in ast.walk(pohon):
    if isinstance(n, ast.Call):
        for kw in n.keywords:
            if kw.arg == "task_id":
                op = n.func.id if isinstance(n.func, ast.Name) else n.func.attr
                print(f"{kw.value.value:<22} <- {op}")

# urutan ketergantungan
for n in ast.walk(pohon):
    if isinstance(n, ast.Expr) and isinstance(n.value, ast.BinOp):
        print(ast.unparse(n.value).replace(" >> ", "  ->  "))

Peringatan jujur: Airflow tidak terpasang di lingkungan tempat modul ini disusun — saya sudah mencoba dan gagal membangunnya. Jadi tidak ada satu pun kode Airflow yang saya jalankan. Yang saya jalankan adalah pembedahan ast di atas, dan itu berjalan tanpa Airflow karena DAG memang berkas Python. Untuk melihat Airflow bekerja sungguhan, kamu butuh aksesnya di tempat kerja.

2

Skrip yang benar-benar berguna

function kirimPeringatanStokMenipis() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("Stok");
  const data  = sheet.getDataRange().getValues();   // baris 0 = judul
  const menipis = [];

  for (let i = 1; i < data.length; i++) {
    const nama = data[i][0];
    const sisa = data[i][2];
    const min  = data[i][3];
    if (sisa < min) {
      menipis.push(nama + ": sisa " + sisa + ", minimum " + min);
    }
  }

  if (menipis.length > 0) {
    MailApp.sendEmail(
      "gudang@perusahaan.co.id",
      "Peringatan stok: " + menipis.length + " barang di bawah minimum",
      menipis.join("\n")
    );
  }
}
LAKUKAN Buka Google Sheets → Extensions → Apps Script, tempel, ganti alamat email, lalu Run. Izinkan aksesnya sekali. Setelah itu: Triggers → Add Trigger → Time-driven → Day timer. Sekarang ia jalan sendiri tiap hari.
Perhatikan if (menipis.length > 0). Tanpa baris itu, skrip mengirim email kosong setiap hari, dan dalam seminggu tidak ada yang membacanya lagi. Ini pelajaran yang sama dengan Bekal Kirim Hasil: kirim hanya kalau ada yang perlu dikirim.

Ujian: enam soal

1. QUERY() di Sheets memakai apa untuk menunjuk kolom, dan
   kenapa itu berbahaya?
2. Dashboard melaporkan rata-rata transaksi Rp 2,57 juta.
   Data mentahnya Rp 131.642. Apa yang terjadi?
3. Tulis rumus rata-rata tertimbang yang benar.
4. Di DAG: [a, b] >> c >> d. Kalau b gagal, apa yang jalan?
5. Skrip Apps Script berhenti di menit ke-6, separuh pekerjaan
   selesai. Apa yang harus kamu lakukan?
6. Klien minta laporan bulanan yang bisa dia saring sendiri

Kunci jawaban

1. Huruf kolom (A, B, C), bukan nama kolom. Kalau ada yang menyisipkan kolom, rumusnya menghitung kolom yang salah tanpa error. Lindungi rentangnya, dan pasang sel pemeriksa total.

2. Rata-rata dari rata-rata. Cabang dengan 20 transaksi diperlakukan seberat cabang dengan 980. Terukur: 19,56 kali terlalu tinggi.

3. sum(rata2_i × n_i) / sum(n_i). Diuji memberi Rp 131.642 — sama persis dengan rata-rata data mentah.

4. a tetap jalan (paralel dengan b). c dan d tidak jalan, karena c menunggu keduanya selesai.

5. Jangan menambal skripnya — pindahkan pekerjaannya ke Python. Batas 6 menit itu keras, dan skrip yang terpotong tidak memberi tahu siapa pun. Sementara itu, periksa data mana yang sudah terlanjur diproses.

6. Looker Studio (atau Metabase kalau perusahaannya punya). Bukan Streamlit, karena Streamlit butuh server yang kamu jalankan dan rawat; klien tidak bisa sekadar membuka tautan setahun kemudian.

Buka jawabannya

Harga Satuan = 185,0. Harga cat sesungguhnya 185.000. Pandas membaca teks "185.000" sebagai bilangan desimal 185 koma nol nol nol — karena di sebagian besar dunia, titik adalah pemisah desimal. Tiga angka nol hilang, tanpa satu pun pesan error, dan hasilnya float64 yang terlihat sangat meyakinkan.

Jadi obatnya bukan "hati-hati", tapi kebiasaan: untuk berkas dari luar, baca dulu semuanya sebagai teks — dtype=str — lalu kamu yang memutuskan mana yang jadi angka dan bagaimana caranya. Jangan biarkan pandas menebak, karena tebakannya benar 95% dan salahnya tidak bersuara.

import pandas as pd, re
pd.set_option("display.width", 200)
BERKAS = "Laporan Penjualan Toko Sumber Rejeki.xlsx"

def ke_angka(s):
    if pd.isna(s): return pd.NA
    t = re.sub(r"[^0-9\-]", "", str(s))
    return int(t) if t not in ("", "-") else pd.NA

raw = pd.read_excel(BERKAS, skiprows=5, dtype=str)
raw = raw.drop(columns=[c for c in raw.columns if str(c).startswith("Unnamed")])

# 1. angka kontrol dari baris subtotal, DIAMBIL SEBELUM dibuang
sub = raw[raw["Nama Barang"].astype(str).str.startswith("TOTAL BULAN", na=False)]
KONTROL = int(sub["Jumlah"].map(ke_angka).sum())

# 2. baris transaksi = baris yang kolom No-nya benar-benar angka
d = raw[raw["No"].fillna("").str.fullmatch(r"\d+")].copy()

# 3. angka
for asal, baru in [("Qty","qty"), ("Harga Satuan","harga"), ("Jumlah","jumlah")]:
    d[baru] = d[asal].map(ke_angka).astype("Int64")

# 4. tanggal tiga format sekaligus
d["tanggal"] = pd.to_datetime(d["Tanggal"], format="mixed", dayfirst=True, errors="coerce")

# 5. nama pelanggan — perhatikan urutannya
d["pelanggan"] = (d["Pelanggan"]
    .str.strip().str.replace(r"\s+", " ", regex=True)      # sebelum astype(str)!
    .str.title()
    .str.replace(r"^(Cv|Pt|Ud|Cv\.|Pt\.)\s+", lambda m: m.group(1).upper().rstrip(".") + " ", regex=True)
    .replace({"-": pd.NA})
    .fillna("Tanpa Nama"))

# 6. kode barang
d["kode"] = d["Kode Barang"].str.upper().str.replace(r"[\s\-]", "", regex=True)
d["retur"] = d["qty"] < 0

print("=== PEMERIKSAAN ===")
print("baris transaksi     :", len(d))
print("tanggal gagal dibaca:", int(d["tanggal"].isna().sum()))
print("nilai kosong        :", int(d[["qty","harga","jumlah"]].isna().sum().sum()))
hasil = int(d["jumlah"].sum())
print("total bersih        :", f"{hasil:,}".replace(",","."))
print("angka kontrol       :", f"{KONTROL:,}".replace(",","."))
print("selisih             :", hasil - KONTROL)
print("cek harga x qty     :", int((d["qty"]*d["harga"] != d["jumlah"]).sum()), "baris tidak konsisten")

print("\n=== HASIL 1: omzet per bulan ===")
d["bulan"] = d["tanggal"].dt.strftime("%Y-%m")
print(d.groupby("bulan").agg(transaksi=("jumlah","size"), omzet=("jumlah","sum")).to_string())

print("\n=== HASIL 2: lima barang teratas ===")
print(d.groupby("kode").agg(unit=("qty","sum"), omzet=("jumlah","sum"))
        .sort_values("omzet", ascending=False).head(5).to_string())

print(d.groupby("pelanggan").agg(nota=("jumlah","size"), omzet=("jumlah","sum"))
        .sort_values("omzet", ascending=False).head(6).to_string())

r = d[d["retur"]]
print("jumlah retur:", len(r), "| nilai:", f'{int(r["jumlah"].sum()):,}'.replace(",","."),
      "| persen dari omzet kotor:",
      round(abs(r["jumlah"].sum()) / d.loc[~d["retur"],"jumlah"].sum() * 100, 2), "%")

Empat hal di kunci itu yang layak kamu tiru, bukan sekadar salin:

  1. Angka kontrol diambil sebelum barisnya dibuang. Enam baris "TOTAL BULAN" dijumlahkan lebih dulu jadi Rp 140.581.000, baru dihapus. Di akhir, hasil bersihmu dicocokkan ke angka itu dan selisihnya harus nol. Tanpa ini kamu cuma berharap pembersihanmu benar.
  2. Barisnya disaring pakai str.fullmatch(r"\d+"), bukan dropna(). Kalau kamu cuma membuang baris kosong, tiga baris footer — "Dicetak oleh: Admin Kasir" dan kawan-kawan — akan lolos, karena kolom No-nya terisi teks. Hasilnya 170 baris, bukan 167, dan tiga transaksi hantu bertanggal kosong masuk ke laporanmu.

"""Kasus 2 — Klinik Pratama Sehat Bersama.

import random, csv
from datetime import date, timedelta
from openpyxl import Workbook

rng = random.Random(7)

NAMA = [
 (1, "Siti Nurhaliza"), (2, "Ahmad Fauzi"), (3, "Dewi Lestari"), (4, "Bambang Wijaya"),

VARIASI = {
 1: ["Siti Nurhaliza", "Siti Nurhalizah", "SITI NURHALIZA", "siti nurhaliza"],
 4: ["Bambang Wijaya", "Bambang Widjaja", "BAMBANG WIJAYA"],
 9: ["Fitri Handayani", "Fitri Handayanti"],

PENJAMIN = ["BPJS", "bpjs", "B.P.J.S", "BPJS Kesehatan", "Umum", "umum", "UMUM",

kunjungan = []

for _ in range(240):
    kode += 1

        digandakan += 1

                      k["tgl"].strftime("%Y-%m-%d"),
                      f"{k['tarif']:.2f}".replace(".", ","),
                      f"{diskon*100:.2f}".replace(".", ","),
                      f"{total:.2f}".replace(".", ",")])

cocok dengan saldo? True adalah baris terpenting di seluruh keluaran itu. Aging disusun lewat jalur yang sama sekali berbeda dari saldo — per faktur, diurutkan tanggal, dengan pembayaran diterapkan berurutan. Dua jalur berbeda yang bertemu di angka yang sama adalah bukti; satu jalur saja cuma harapan.

Kenapa FIFO. Data pembayaran cuma menyebut jumlah dan nama, bukan faktur mana yang dilunasi. Jadi kamu harus memilih aturan penerapan, dan FIFO — tertua dulu — adalah yang lazim dan yang paling konservatif untuk aging. Sebut asumsi itu di laporanmu. Kalau klien punya bukti bahwa pelanggan tertentu membayar faktur tertentu, aturannya berubah dan angkanya ikut berubah.

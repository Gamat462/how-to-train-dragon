1

Satu kotak, banyak isi

Sejauh ini satu variabel menyimpan satu nilai. List menyimpan banyak nilai berurutan dalam satu nama, ditandai kurung siku [ ]:

4

len( ) artinya "berapa banyak isinya" — sama seperti COUNT(*) di SQL yang kamu pakai sejak Hari 2.

2

Mengambil satu isi — dan jebakan nomor nol

print(produk[0])
print(produk[1])
print(produk[3])
HARUS MUNCUL

Kopi Susu
Americano
Croissant

Nomornya mulai dari 0, bukan 1. Item pertama adalah produk[0]. Item keempat adalah produk[3]. Kalau ada 4 item, nomor tertingginya 3.

Ini sumber kebingungan nomor satu bagi pemula, dan penyebab IndexError yang kamu bikin kemarin. Cara mengingatnya: nomor itu bukan "urutan ke-", tapi "berapa langkah dari awal". Item pertama = nol langkah dari awal.

Menghitung dari belakang pakai angka minus:

print(produk[-1])
print(produk[-2])
HARUS MUNCUL

Croissant
Roti Bakar

[-1] = yang terakhir. Ini sering dipakai karena kamu tidak perlu tahu ada berapa isinya.

3

Slicing: mengambil sepotong

angka = [10, 20, 30, 40, 50, 60]
print(angka[0:3])
print(angka[:3])
print(angka[2:])
print(angka[-2:])
print(angka[:-2])
HARUS MUNCUL

[10, 20, 30]
[10, 20, 30]
[30, 40, 50, 60]
[50, 60]
[10, 20, 30, 40]

Aturan yang wajib dihafal: angka sesudah titik dua tidak ikut. [0:3] memberi item 0, 1, 2 — tiga item, bukan empat.
  • Kosongkan sebelum titik dua = "dari awal"
  • Kosongkan sesudah titik dua = "sampai habis"
  • Angka minus = hitung dari belakang
Kamu akan bertemu ini di dua tempat penting. Hari 50: bulanan.iloc[:3] = tiga bulan pertama. Hari 84: latih, uji = s[:-28], s[-28:] — memisahkan 28 hari terakhir sebagai data uji ramalan. Kalau kamu salah membaca notasi ini, kamu salah memisahkan data latih dan data uji, dan seluruh hasil ramalannya jadi tidak sah.

Masalah yang dipecahkan dictionary

Kalau harga disimpan sebagai list, kamu harus ingat bahwa Americano ada di nomor 1:

harga_list = [22000, 18000, 15000]
print(harga_list[1])   # 18000 — tapi ini harga apa? kamu harus ingat sendiri

Dictionary menyimpan namanya sekalian, ditandai kurung kurawal { }:

harga = {"Kopi Susu": 22000, "Americano": 18000, "Roti Bakar": 15000}
print(harga["Americano"])
print(len(harga))
HARUS MUNCUL

18000
3

Bagian kiri titik dua namanya key (kunci), kanannya value (nilai). Ambil isinya pakai kurung siku berisi key: harga["Americano"].

3

Menambah, mengubah, memeriksa

harga["Croissant"] = 20000      # menambah yang belum ada
harga["Kopi Susu"] = 23000      # mengubah yang sudah ada
print(harga)

print("Latte" in harga)
print(harga.get("Latte", 0))
HARUS MUNCUL

{'Kopi Susu': 23000, 'Americano': 18000, 'Roti Bakar': 15000, 'Croissant': 20000}
False
0

.get(key, cadangan) penting. Kalau kamu tulis harga["Latte"] untuk key yang tidak ada, Python melempar KeyError dan kodenya berhenti. .get() memberi nilai cadangan alih-alih berhenti — dipakai di Hari 27 jalur migas: harga.get(bulan, 65) artinya "ambil harga bulan itu, kalau tidak ada pakai 65".
4

Di mana kamu akan bertemu ini

Hari 84, efek hari dalam seminggu terhadap omzet:

efek_hari = {0:-0.10, 1:-0.12, 2:-0.06, 3:0.02, 4:0.14, 5:0.24, 6:0.12}

Key-nya angka 0-6 (0 = Senin, 5 = Sabtu), value-nya seberapa jauh omzet hari itu dari rata-rata. Sabtu 0.24 artinya 24% di atas rata-rata. Kamu tinggal efek_hari[5] untuk mengambilnya.

Kapan pakai list, kapan dictionary? Kalau urutannya penting dan kamu mengambil "yang ke-berapa" → list. Kalau kamu mengambil "yang mana" berdasarkan nama/kode → dictionary. Dalam pekerjaan analis, dictionary paling sering dipakai sebagai tabel pencarian: kode → nama, bulan → harga, cabang → kota.

1

Membandingkan dua nilai

print(22000 > 18000)
print(22000 == 22000)
print(22000 != 18000)
print(15000 >= 15000)
HARUS MUNCUL

True
True
True
True

Perhatikan == dengan dua tanda sama dengan. Satu = artinya "simpan ke" (Bekal 2). Dua == artinya "apakah sama dengan?". Menukar keduanya adalah kesalahan paling sering di seluruh dunia pemrograman.

Spasi di awal baris = tanda kepemilikan

Di kebanyakan bahasa lain, blok kode ditandai kurung kurawal. Python memakai menjorok (indentasi). Baris yang menjorok "milik" baris di atasnya.

    print("B — ini juga")

HARUS MUNCUL

Hanya C — ini rata kiri, jadi SELALU jalan

A dan B tidak muncul karena 5000 tidak lebih besar dari 10000. C muncul karena dia bukan milik if.

Gunakan Tab, dan jangan campur Tab dengan spasi. Colab otomatis menjorokkan baris setelah kamu mengetik titik dua dan menekan Enter — biarkan saja, jangan ditambah manual. Kalau muncul IndentationError (kamu sudah bikin sendiri di Bekal 3), periksa apakah ada baris yang menjoroknya tidak konsisten.

BEKAL 8

± 60 menit

Akhir hari ini kamu bisa: membaca dua bentuk terakhir yang tersisa, lalu membuktikan kesiapanmu dengan membongkar potongan kode yang selama ini jadi tembok — baris demi baris.

1

List comprehension: perulangan yang dipadatkan

Ingat pola kumpul dari kemarin:

kuadrat = []
for x in [1, 2, 3, 4]:
    kuadrat.append(x * x)
print(kuadrat)

Python punya cara menulis hal yang persis sama dalam satu baris:

kuadrat = [x * x for x in [1, 2, 3, 4]]
print(kuadrat)
KEDUANYA MEMBERI

[1, 4, 9, 16]

Cara membacanya: dari tengah dulu, baru ke depan.
  • Lihat bagian for x in [1,2,3,4] lebih dulu → "untuk setiap x"
  • Baru lihat bagian depan x * x → "kumpulkan x dikali x"
  • Kurung siku di luar → "hasilnya jadi list"

Jadi: "buat list berisi x×x, untuk setiap x di dalam [1,2,3,4]".

Latihan membaca — apa isi hasil?

harga = [22000, 18000, 15000, 20000]
hasil = [h * 2 for h in harga]
print(hasil)
Tebak dulu, baru jalankan dan buka ini

[44000, 36000, 30000, 40000] — tiap harga dikali dua.

2

Kapan pakai yang mana

PakaiKalau
for biasaada beberapa langkah di dalamnya, atau kamu masih belajar
comprehensioncuma satu operasi sederhana per item
Jangan merasa wajib memakai comprehension. Keduanya menghasilkan hal yang sama, dan versi for biasa sering lebih mudah dibaca. Kamu belajar ini supaya bisa membaca kode orang lain — termasuk kode di kurikulum ini — bukan supaya harus selalu memakainya.
3

def: memberi nama pada sekumpulan langkah

Kalau kamu mengerjakan hal yang sama berkali-kali dengan angka berbeda, bungkus jadi fungsi:

def laba_per_porsi(harga, biaya):
    hasil = harga - biaya
    return hasil

print(laba_per_porsi(22000, 9000))
print(laba_per_porsi(20000, 11000))
HARUS MUNCUL

13000
9000

BagianArtinya
def"aku mau membuat perintah baru"
laba_per_porsinama perintahnya — kamu yang menentukan
(harga, biaya)kotak kosong yang diisi saat dipanggil

return berbeda dari print. print cuma menampilkan di layar; hasilnya tidak bisa dipakai lagi. return menyerahkan nilainya sehingga bisa disimpan atau dihitung lagi. Fungsi tanpa return menghasilkan None — penyebab bingung yang sangat umum.

Buktikan sendiri bedanya:

    print(a - b)

Angkanya tampil, tapi x kosong — karena fungsinya tidak return apa pun.

Ujian sesungguhnya: bongkar kode Hari 24

Inilah potongan yang selama ini jadi tembok. Sebelum membaca penjelasannya, coba baca sendiri dulu — kamu sekarang tahu setiap bagiannya.

for n in [5, 30, 100]:
    hasil = [np.random.choice(populasi, size=n, replace=False).mean() for _ in range(1000)]
    hasil = np.array(hasil)
    print(f"n={n}: rata-rata dari 1000 sampel = {round(hasil.mean())}, sebaran (std) = {round(hasil.std())}")
Buka setelah kamu mencoba membacanya sendiri

Baris 1 — for n in [5, 30, 100]:
Perulangan (Bekal 7). Isi list-nya dijalankan tiga kali: sekali dengan n = 5, sekali 30, sekali 100.

Baris 2 — hasil = [ ... for _ in range(1000)]
List comprehension (langkah 1 hari ini). Baca dari tengah: for _ in range(1000) = "lakukan 1.000 kali, nomor putarannya tidak dipakai" (garis bawah, Bekal 7). Bagian depannya np.random.choice(...).mean() = "ambil n orang secara acak, hitung rata-ratanya". Jadi: kumpulkan 1.000 rata-rata, tiap kali dari sampel acak yang berbeda.

Baris 3 — hasil = np.array(hasil)
Mengubah list biasa jadi bentuk yang bisa dihitung statistiknya. Sama seperti int("22000") di Bekal 2 — mengubah bentuk, bukan isinya.

Baris 4 — print(f"n={n}: ... {round(hasil.mean())} ...")
f-string (Bekal 7). {n} diganti 5/30/100, {round(hasil.mean())} diganti rata-rata dari 1.000 angka tadi, dibulatkan.

Satu-satunya yang belum kamu kenal adalah np.random.choice dan .mean() — dan keduanya memang dijelaskan di Hari 24 itu sendiri. Semua kerangkanya — perulangan, comprehension, garis bawah, f-string — sekarang sudah kamu kuasai.
